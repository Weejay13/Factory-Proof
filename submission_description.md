# Submission copy

**Project title:** FactoryProof

**Short description:** A BAND-native software factory that plans, builds, verifies, and gates Pocketful wallet changes with observable evidence.

**Long description:** FactoryProof is a track-agnostic software factory for the Dark Factory hackathon. Its coordinator scopes a case and recruits a builder, verifier, and critic. The verifier can block a candidate, the critic can challenge unsupported evidence, and a human owner controls promotion. The reference Pocketful run demonstrates a transfer that preserves money under retries, rejects malformed or insufficient transfers, and records an audit trail. The repository contains the generic mandates, the factory runner, four stage services, clean-container configuration, and a BAND integration path.

**Technology tags:** BAND, BAND Desktop, Python, Docker, software factory, multi-agent systems, Pocketful, API, concurrency, idempotency

**Category:** Developer tools / AI agents

**Selected track:** Pocketful
