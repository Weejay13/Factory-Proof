Contract guarantees

  • Retries return the original result — no double spend.
  • Concurrent requests cannot move money twice (atomic transfer write under lock).
  • Amounts stay exact using integer cents — no floating-point drift.
  • Insufficient funds, malformed payloads, and reused keys for different amounts are rejected.
  • Every wallet and transfer is appended to the audit stream.
