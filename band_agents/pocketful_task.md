# Pocketful reference task

Send this as the task in the BAND room after registering the four seats:

> Build a small Pocketful-style wallet transfer service. The service must create a wallet, record a transfer, reject malformed or insufficient funds, return the original result for a repeated idempotency key, and preserve the exact amount under concurrent retries. Use integer cents rather than floating point, and state the official time-zone and rounding policy once the stage specification is released. Add a visible audit trail and a small human approval gate before the release packet is accepted. Use the official stage harness once the kickoff specification is available.

The task, not the mandates, contains the track-specific contract. Replace it with the official stage requirements when they are released.
