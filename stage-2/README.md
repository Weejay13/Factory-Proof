# Stage 2 — Pocketful Web UI

This folder adds the browser UI over the stage-1 JSON API. The interface exposes wallet creation, transfer submission, and an audit list with explicit `data-testid` attributes for the official harness.

```bash
python3 app.py --host 127.0.0.1 --port 8080
```

The official kickoff specification remains authoritative for exact screens, selectors, and endpoint names.
